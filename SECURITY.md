# Security Policy

## Supported Versions

Only the latest release of **Pulse** is currently supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.0   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please **do not open a public issue**. 

Instead, send a private security advisory through GitHub or report it directly to **[drJhonatan00](https://github.com/drJhonatan00)**.

### Response Time
We aim to acknowledge reports within 72 hours and provide a fix or patch as soon as possible.
